# v0.2.0 vs v0.1.0 on the demo data

Both runs use the bundled demo (`demo/samplesheet.csv`: GM12878 ×2 = `control`, H1 ×2 = `treatment`,
10,000 reads per sample), `GRCh38.genome.fa`, `gencode.annotation.gtf` and
`TEtranscript_hg38_rmsk_TE.gtf`, with `-profile singularity` on the same host.

| Run | Directory (under `Tools/nf-LongIso_v2_runs/`) | Settings |
|---|---|---|
| v0.1.0 | `baseline_v0.1.0_demo` | see `docs/dev/baseline_v0.1.0.md` |
| v0.2.0 | `demo_v0.2.0` | defaults (`--te_count_mode exon`), `--max_cpus 32 --max_memory 128.GB`; 31 tasks, 12 min 20 s, no retries |
| v0.2.0 span | `demo_v0.2.0_span` | as above plus `--te_count_mode span`, `-resume` (only TE_ANALYSIS, TE DESeq2, versions and MultiQC re-ran) |
| v0.2.0 r2 | `demo_v0.2.0_r2` | after the methodological review (commit `fa191d3`), defaults, `--max_cpus 32 --max_memory 128.GB`; fresh work directory, 43 tasks, 13 min 44 s, no retries |
| v0.2.0 r3 | `demo_v0.2.0_r3` | after the second review (commit `755609d`), defaults, same limits; `-resume` on the r2 work directory (26 tasks cached, 17 run), 7 min 12 s, no retries |

Bambu numbers its novel transcripts (`BambuTx*`) differently from run to run (same 131 transcripts,
same structures and counts; see the baseline document), so comparisons of individual rows exclude
`BambuTx*` IDs. "Floating-point noise" means relative differences below 1e-12.

Metrics were produced with `tests/summarize_results.py`; row-level checks are described in each section.

## Alignment (issues 13, 14)

v0.2.0 builds the minimap2 index once (`-x splice`, 18.5 GB peak, 1 min 33 s) and aligns with
`zcat | awk | minimap2 | samtools sort` in the mulled minimap2 2.28 + samtools 1.20 container
(v0.1.0: minimap2 2.28 and samtools 1.19.2, index rebuilt for each sample, SAM written to disk). The
alignments are unchanged: bigWigs, junction BEDs and the samtools stats sections are byte-identical.
Peak memory per alignment task fell from 18.5-21.8 GB (index built inside each task) to 15.7 GB.

## Differential expression (issues 6, 7)

`DE_transcripts/DE_results.csv` reproduces v0.1.0's `DE_genes/DE_results.csv` (which was transcript
level): same IDs, same `gene_id` column, statistics equal up to 5.1e-13 relative difference.
`DE_genes/` now holds the gene-level analysis of `counts_gene.txt` (78,936 genes). The reference
condition was chosen automatically (`control`), so fold changes keep the v0.1.0 direction
(treatment vs control). The demo has no significant genes or transcripts at either level.

## TE analysis (issues 10, 12)

* **span mode** (comparison option) applies the v0.1.0 counting rule. Its count-dependent outputs match
  v0.1.0 (`TE/`, span run vs v0.1.0 baseline):

  | File | Result |
  |---|---|
  | `TE_family_counts.tsv`, `TE_instance_counts.tsv` | byte-identical |
  | `DE/DE_TE_Instance_results.csv`, `DE/norm_counts_Family.csv`, `DE/norm_counts_Instance.csv` | byte-identical |
  | `DE/pca_*.pdf`, `DE/volcano_*.pdf` | identical apart from the PDF creation timestamp |
  | `DE/DE_TE_Family_results.csv` | same rows and NA pattern; values differ by at most 1.6e-13 (relative). Two independent v0.1.0 runs also differ at this level |
  | `isoform_TE_annotation.tsv` | new in v0.2.0 (not written by v0.1.0) |

  The annotation and exonization tables do not depend on the counting mode. (The
  `isoform_TE_exonization.tsv` stored in `demo_v0.2.0_span` was written by an intermediate build that
  used the v0.1.0 exonization test in span mode; with the release code it is the same as in exon mode,
  0 rows on the demo.)
* **exon mode** (default) counts 467 subfamilies (span: 409) and 19,562 reads (span: 33,730). 89.3 % of
  the span-mode counts come from transcripts whose assigned TE lies only in an intron. Exon mode finds
  HERVH-int (log2FC +10.0, padj 0.004) and LTR7 (log2FC +8.6, padj 0.019) up in H1 embryonic stem cells,
  consistent with their known activity in human ESCs; span mode finds no significant subfamily. See
  `docs/te_count_mode_comparison.md`.
* **isoform_TE_exonization.tsv** (exon mode): v0.1.0 reported 2 events, both novel **terminal** exons
  with a single splice site (BambuTx17, first exon on the minus strand; BambuTx87, last exon), i.e.
  without junction support at both ends; they passed only because v0.1.0 tested window overlaps. Exon
  mode reports 0 strict events and lists both exons in `isoform_TE_annotation.tsv` (MLT1A0: category TSS,
  `exon_positions` first; Harlequin-int: autonomous, 81 % of the transcript, `exon_positions` last), with
  junction support at their single splice site. The test is the same in both counting modes.

## Changes attributable to other fixes

* Floating-point noise in DESeq2 and IsoformSwitchAnalyzeR expression values, and Bambu ID numbering:
  also seen between two v0.1.0 runs.
* APA q-values (71 of 1,564): simulated Fisher p-values are random in v0.1.0 and seeded in v0.2.0.
* `APA_gene_summary.csv` values: different site selection (largest instead of smallest |dPAU|).
* `isoform_TE_exonization.tsv`: junction validation (`docs/dev/verification.md`, V3), independent of the
  counting mode.

## Methodological review: `demo_v0.2.0` vs `demo_v0.2.0_r2`

Effect of the fixes A1-A4 (`docs/dev/review_v0.2.0_verification.md`) and the new outputs B1-B5 on the
demo. Unchanged: bigWigs, samtools stats, `DE_genes/`, `TE_family_counts.tsv` and `TE_instance_counts.tsv`
(byte-identical); Bambu (identical apart from the run-to-run numbering of the 131 `BambuTx` IDs);
`DE_transcripts/` (≤ 5.1e-13 relative difference) and SUPPA2 PSI (≤ 2.2e-16); the categories of
`isoform_TE_annotation.tsv` (only `junction_supported` changes, see A1).

### A1 junctions

| Sample | Old BED rows | Old intervals on both strands | New rows | Strand `.` | Annotated | Canonical motif |
|---|---|---|---|---|---|---|
| GM12878_demo_rep1 | 16,050 | 3,071 | 12,892 | 5 | 96.7 % | 99.5 % |

The duplicated (wrong-strand) copies are gone; 30-154 intervals per sample came only from secondary or
supplementary alignments and are no longer reported. All new intervals were in the old files.
In the TE annotation, 173 of 255,480 isoform-TE pairs change `junction_supported` from `yes` to `no`
(they were supported only by wrong-strand junctions); strict exonization events stay at 0.

### A2 APA

Old: 1,041 of 1,564 PAS clusters significant in 450 genes (Fisher test on condition-mean pseudo-counts).
New: 75 PAS in 37 genes testable, 3 genes significant (gene q < 0.05; RPL14 and NASP distal, RPS14
proximal), all three also in the old list. Internal priming: 0 of 131 novel ends removed. See
`docs/dev/apa_method_comparison.md`.

### A3 TE normalisation

| Size factors | GM12878 rep1 | GM12878 rep2 | H1 rep1 | H1 rep2 |
|---|---|---|---|---|
| Old (transcripts + TEs) | 0.983 | 1.000 | 1.305 | 0.868 |
| New (genes) | 0.900 | 1.000 | 1.493 | 0.841 |

TE family log2 fold changes shift by a median of −0.12 (Pearson r 0.9997 old vs new). Significant
families (padj < 0.05) go from 2 (HERVH-int, LTR7) to 11: LTR7, HERVH-int and THE1A up in H1; L1PA4,
LTR2B, Ricksha_a, Ricksha_c, Charlie10a, L1MD2, LTR90A and MamRep1894 down. TE instances: 0 in both.
The old size factors were pulled towards the TE rows, which are sums of transcript counts; the new ones
reflect library depth of the gene counts. With 2 × 10,000 reads per condition the extra families are
low-count calls and should not be over-interpreted.

### A4 promoters

proActiv (`demo_v0.2.0`): 160,497 promoters, 25,638 NA in all samples (single-exon only), 890 / 1,208
active (control / treatment), no alternative promoters. These proActiv results (like those of v0.1.0)
only count junctions on the plus strand: all 79,200 minus-strand promoters have zero counts. This was
fixed afterwards (proActiv reads the stranded junction tables; proActiv is the default method again,
`results/proactiv/`). After the fix (`demo_v0.2.0_r3`): plus strand 4,491 promoters with counts, active
880 / 1,202; minus strand 4,381 with counts, active 858 / 1,143; no alternative promoters (see
`docs/dev/promoter_method_comparison.md`). tss (`demo_v0.2.0_r2/promoter/`, now optional and written to
`results/promoter_tss/`): 199,302 promoters, none NA, 2,591 / 3,241 active,
including 112 active promoters made only of single-exon transcripts; 3 genes with differential promoter
usage (HSPD1, RPL14, UGP2), all with an IsoformSwitchAnalyzeR ATSS event. See
`docs/dev/promoter_method_comparison.md`.
